# Unsere Bergabenteuer

Responsive Website zum Familien-Alpenführer „Ötztal & Dolomiten 2026“.

## Lokal starten

```bash
npm install
npm run dev
```

Danach die im Terminal angezeigte lokale Adresse öffnen.

## Inhalte ändern

- `app/page.tsx` – Texte, Touren und Links
- `app/globals.css` – Gestaltung und responsive Regeln
- `public/images/` – Tourenbilder
- `public/downloads/` – PDF-Fassung
- `public/og.png` – Vorschau beim Teilen eines Links

## Prüfen

```bash
npm run lint
npm run build
```

Das Projekt ist als eigenständiges Git-Repository angelegt und kann direkt mit
einem GitHub-Repository verbunden werden.
